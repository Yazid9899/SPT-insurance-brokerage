# Open Cover Smoke Checklist

- [ ] Open `/open-covers` and verify required columns render for each row.
- [ ] Create a new open cover agreement with unique reference.
- [ ] Attempt duplicate reference and confirm error is shown.
- [ ] Open detail page and verify declarations list is visible.
- [ ] Apply declaration status filter and confirm list changes.
- [ ] Edit insurer rate and save agreement.
- [ ] Verify existing declarations retain historical insurer rate.
- [ ] Go to `/cases/new` and choose `OPEN_COVER` as cover type.
- [ ] Confirm open cover selector shows active agreements only.
- [ ] Select an agreement and verify client fields + insurer rate are auto-filled.
- [ ] Confirm insurer rate and currency are locked while client rate remains editable.
- [ ] Submit case and verify it appears in `/cases`.
